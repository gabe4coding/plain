# Make-it-fail audit, 2026-10-16

Scope: `src/` (80 non-test files, 9982 lines), `scripts/`, the agent notes and the CI workflows, at `origin/main`
29400e1. This audit is a report only. It changes no code. Pick the rows to build.

Method: a count script over `src/`, three read-only agents (types, boundaries, text-only rules and fixtures), then
a manual check of the bugs below. Frequency comes from occurrence counts and from `kb find` hits in past sessions.

Ladder levels: 1 type system, 2 generated code, 3 architecture check, 4 lint or grep gate, 5 test, 6 doc.
